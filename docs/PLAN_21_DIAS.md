# Plan de 21 días

El MVP se implementa en orden de valor verificable, aunque esta ejecución automatizada comprime el calendario.

1. Días 1–3: auditoría, modelo de evidencia, migración y seed de 55 oportunidades.
2. Días 4–7: importación segura, deduplicación y exportaciones.
3. Días 8–11: INE, Eurostat y GitHub, snapshots y tendencias.
4. Días 12–16: seis pantallas, responsive, accesibilidad y autenticación single-user remota.
5. Días 17–19: cron diario, inbox y operación resiliente.
6. Días 20–21: e2e, revisión visual, documentación y corrección de aceptación.

Apps/juegos, inversores, YC, TED completo y pronósticos con backtesting quedan en segunda etapa hasta disponer de datos y cobertura suficientes.
